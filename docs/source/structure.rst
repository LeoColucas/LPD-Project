Estrutura do Projeto
======================

O projeto encontra-se organizado por componentes, separando código-fonte,
configurações, dados persistentes, material criptográfico e relatórios.

Diretórios principais
---------------------

::

   Projeto/
   ├── main.py
   ├── core/
   ├── modules/
   ├── scripts/
   ├── configs/
   ├── data/
   ├── downloads/
   ├── reports/
   ├── client_keys/
   ├── server_data/
   └── docs/
